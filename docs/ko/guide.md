# 사용 안내

[English](../en/guide.md)

## 사용법

### 처음 써 보기

1. `./amsil`을 실행하고 **[새 프로젝트]** 로 프로젝트 파일(`이름.amsil`)을 만든다.
2. **[폴더 가져오기]** 로 RAW가 든 폴더를 고른다. 왼쪽에 사진 목록이 뜬다.
3. 사진을 누르면 가운데에 미리보기가 나온다. 오른쪽에서 **프리셋**을 누른다.
4. 아래쪽에서 **[출력 폴더…]** 를 정하고 **[전체 내보내기]** 를 누른다.

이것으로 끝이다. 나머지 기능은 필요할 때 쓰면 된다. 보정 내용은 누를 때마다 프로젝트 파일에 저장되므로 따로 저장할 필요가 없다.

### 화면 구성

맨 위의 그림이 작업 화면이다.

| 자리 | 있는 것 |
|---|---|
| 위쪽 줄 | 프로젝트 이름, [폴더 가져오기], [스크린샷], [프로젝트 닫기], AI 실행 환경(`GPU`)과 [AI 정보], [로그 열기], 밝기 모드, 언어 |
| 왼쪽 | 가져온 사진의 목록. 이름 옆에 사진의 종류(풍경, 음식 등)가 적힌다 |
| 가운데 | 고른 사진의 미리보기. 보정을 바꾸면 바로 반영된다. 위의 [비교]를 켜면 보정 전과 나란히 보인다 |
| 오른쪽 | 프리셋, 마스크, 피부 보정, 프레임, 캡처 샤픈, 노이즈 제거 |
| 아래쪽 줄 | 출력 폴더, 품질, [선택 내보내기], [전체 내보내기] |
| 맨 아래 | 알림, 내보내는 동안의 자원 사용량과 진행 막대, 남은 시간 |

창이 좁으면 위쪽과 아래쪽 줄의 단추가 다음 줄로 넘어가고, 창이 세로로 길면 오른쪽 패널이 아래로 내려간다.

### 조작

| 하고 싶은 일 | 방법 |
|---|---|
| 사진 여러 장 고르기 | Ctrl 또는 Shift를 누른 채 누른다. Ctrl+A는 전체 선택 |
| 앞뒤 사진으로 가기 | 위아래 화살표 |
| 미리보기 확대·축소 | 휠 (커서 위치를 중심으로, 최대 400%) |
| 미리보기 옮기기 | 끌기 |
| 창에 맞춤 ↔ 100% | 미리보기를 두 번 누른다 |
| 보정 전과 후를 나란히 보기 | 미리보기 위의 [비교]. 한쪽을 확대하거나 옮기면 다른 쪽도 같이 움직인다. 나누는 방향은 [자동] [좌우] [위아래], 왼쪽 칸에 보일 것은 [보정 전 RAW] [카메라 JPEG] |
| 창을 그림으로 저장 | [스크린샷] 또는 F12 (프로젝트 파일 옆의 `스크린샷` 폴더) |
| 화면 언어, 밝기 모드 | 위쪽의 [한국어] [English], [라이트] [다크] |

보정은 **선택한 사진 전체**에 적용된다. 마스크만 지금 보는 사진 한 장에 적용된다.

### 프리셋과 세부 보정

- 프리셋을 누르면 바로 적용된다. **강도**로 세기를 조절한다 (0~150%).
- **[자세히]** 를 펼치면 노출, 대비, 하이라이트, 그림자, 색온도, 틴트, 채도, 생동감, 선명도, 샤픈, 비네팅, 흑백을 직접 고칠 수 있다. **[색상별]** 에는 빨강부터 자홍까지 여덟 색의 채도와 밝기가 있다.
- **[보정 초기화]** 는 프리셋, 세부 보정, LUT, 피부 보정을 지운다. 노이즈 제거, 프레임, 마스크, 캡처 샤픈은 남는다.

**프리셋 추천.** 사진을 가져오면 사진마다 음식, 인물, 풍경, 야경, 건축, 기타 가운데 무엇인지 알아본다. 확신이 60% 이상일 때만 목록의 이름 옆에 적고, 맞는 프리셋 단추에 ★를 붙인다. **[추천 프리셋 적용]** 을 누르면 선택한 사진마다 맞는 프리셋이 한꺼번에 들어간다. 건축과 기타에는 맞는 프리셋이 없어 추천하지 않는다. 추천은 제안일 뿐이라, 적용한 뒤에도 바꾸거나 없앨 수 있다.

**프리셋 만들기.** 프리셋은 TOML 파일 하나다. `~/.config/amsil/presets/`에 넣으면 기본 프리셋 뒤에 나타난다.

```toml
name = "따뜻한 오후"
name_en = "Warm afternoon"   # 영어 화면에 보일 이름 (없어도 된다)
category = "landscape"       # 이 종류의 사진에 추천된다 (없어도 된다)

[params]
temp = 0.2          # 색온도: +는 따뜻하게
contrast = 0.1
vibrance = 0.2

[params.hsl]
orange = { sat = 0.1 }
```

쓸 수 있는 항목: `exposure`(EV), `contrast`, `highlights`, `shadows`, `temp`, `tint`, `saturation`, `vibrance`, `clarity`, `sharpen`, `vignette`(-1~1), `mono`(0~1), 그리고 `hsl`의 색상대(`red`, `orange`, `yellow`, `green`, `aqua`, `blue`, `purple`, `magenta`)별 `sat`와 `lum`. 모두 0이 "변화 없음"이다. 기본 프리셋은 저장소의 [`presets/`](../../presets)에 있다.

### LUT

**[LUT 불러오기…]** 로 3D LUT(`.cube`) 파일을 고르면 보정 뒤에 입혀진다. LUT 강도로 원본과 섞는 정도를 정한다.

- 보정이 끝난 sRGB 그림에 입힌다. 그래서 sRGB(Rec.709) 화면용으로 만든 "룩" LUT이 맞다. 로그 영상용 변환 LUT(S-Log → Rec.709 등)은 맞지 않는다.
- 프로젝트 파일에는 LUT 파일의 위치만 저장한다. 파일을 옮기거나 지우면 그 LUT을 쓰는 사진은 내보낼 때 실패로 표시된다.
- 1D LUT은 지원하지 않는다.

### 마스크

사진의 일부분만 따로 보정한다.

1. **[새 마스크]** 를 누른다.
2. 사진에서 고를 곳(하늘, 건물, 사람 등)을 누른다. 그 물체가 골라지고 붉게 표시된다.
3. 빼고 싶은 곳은 오른쪽 단추로 누른다. **[점 되돌리기]** 로 마지막에 누른 곳을 없앤다.
4. 고른 곳에만 줄 노출, 대비, 색온도, 틴트, 채도를 정한다. **[반전]** 을 켜면 고른 곳의 바깥이 보정된다.

- 한 사진에 여러 개를 만들 수 있다.
- 사진마다 처음 누를 때 1초쯤 걸리고, 그다음부터는 바로 반응한다.
- 마스크를 고쳐 쓰는 동안과 [비교]를 켠 동안에는 프레임이 미리보기에서 잠시 빠진다 (누른 자리가 어긋나지 않게, 두 칸의 크기가 같게). 내보낼 때는 그대로 들어간다.

### 피부 보정 (실험 기능)

세기를 올리면 인물의 피부(얼굴과 몸)를 자동으로 찾아, 그 안에서만 얼룩과 고르지 않은 톤을 줄인다.

- 얼굴을 새로 그리거나 모양을 바꾸지 않는다. 가는 결(모공, 잔털)과 큰 명암은 남기고 그 사이 크기의 얼룩만 줄인다. 눈·입술·머리카락 같은 뚜렷한 윤곽은 건드리지 않는다.
- 가까이서 찍은 인물에 잘 듣는다. 멀리 있는 사람이나 밝은 색 가발 등에서는 빗나갈 수 있다.

### 프레임

사진 둘레에 여백을 두르고 그 아래에 촬영 정보를 두 줄로 적는다.

```
Sony DSLR-A900
70mm  f/11  1/200s  ISO 200  ·  2026.11.10
```

| 모양 | 뜻 |
|---|---|
| 하단 띠 | 사진 아래에 띠만 붙인다 |
| 테두리 | 위와 양옆에 얇은 테두리, 아래에 글자가 들어갈 넓은 여백 |
| 1:1, 4:5, 9:16 | 테두리를 두른 뒤 여백을 더해 그 비율로 맞춘다 (SNS에 올릴 때 잘리지 않게) |

- 흰색과 검정 중에서 고른다.
- 사진에 기록되지 않은 값(렌즈 이름 등)은 건너뛴다.
- 비율을 맞추면 그림이 커진다 (가로 사진을 9:16에 넣으면 화소 수가 세 배 가까이 된다). 그만큼 메모리를 더 쓴다.

### 캡처 샤픈

RAW는 원래 카메라 JPEG보다 무르다. 렌즈와 센서 앞의 필터(무아레를 막는 로우패스 필터)가 빛을 조금씩 퍼뜨리기 때문이고, 카메라는 JPEG를 만들 때 이것을 샤픈으로 되돌린다. 암실은 RAW를 읽을 때 같은 일을 한다. RawTherapee의 Capture Sharpening을 옮긴 것으로, 밝기의 흐림을 되돌리고(Richardson–Lucy 디컨볼루션) 경계가 뚜렷한 곳에만 섞는다. 하늘이나 벽처럼 평평한 곳과 하얗게 날아간 곳의 둘레는 건드리지 않는다.

- 모든 사진에 기본으로 켜져 있다. 기본값(반복 20, 대비 문턱 0.4)은 사진 다섯 장을 카메라 JPEG와 견줘 정했다. 품질 55로 압축한 결과의 세부가 카메라 JPEG와 비슷하고(끄면 0.7배쯤), 용량은 10%쯤 는다.
- 오른쪽의 **캡처 샤픈** 묶음에서 바꾼다. 선택한 사진 전체에 적용된다.
  - **반복 횟수** (1~100): 많을수록 흐림을 더 되돌린다.
  - **[세부 설정]**: 반경(되돌릴 흐림의 크기, 기본은 사진에서 구함), 대비 문턱(높을수록 뚜렷한 경계만 샤픈. 자동이면 사진에서 구하는데, 카메라 JPEG보다 1.3배쯤 세고 용량이 더 는다), 모서리 반경(렌즈의 가장자리가 더 흐릴 때 모서리로 갈수록 반경을 더함), 넘치면 멈추기.
- **샤픈 영역 보기**: 캡처 샤픈이 걸리는 곳을 [빨간 표시]로 사진 위에, 또는 흑백 지도(흰색이 샤픈하는 곳)로 보여 준다. 보는 동안에는 프레임이 빠진다.
- 선예도는 100%로 확대해서 판단한다. 전후 비교에서 [카메라 JPEG]를 고르면 같은 이름의 카메라 JPEG와 나란히 볼 수 있다.
- [보정 초기화]는 캡처 샤픈을 건드리지 않는다.
- 이 기능이 없던 버전에서 만든 프로젝트도 캡처 샤픈이 켜진 채로 열린다. 다시 내보내면 예전보다 선명하고 용량이 조금 크다.

### 노이즈 제거

레벨을 정하고 **[적용]** 을 누르면 선택한 사진들에 저장된다.

- 고감도 사진의 노이즈를 거의 다 지운다. 대신 세부가 조금 무뎌지므로, 노이즈가 적은 저감도 사진에는 끄거나 레벨을 낮추는 편이 낫다.
- 위쪽에 `GPU`가 보이면 GPU로 돌고 있는 것이다. `CPU (느림)`이 보이면 눌러서 해결 방법을 볼 수 있다.

### 품질

기본값 55를 권장한다. JPEG 90 수준의 화질이다. 2,400만 화소 사진 두 장으로 잰 용량은 이렇다 (카메라 JPEG는 각각 8.1MB, 7.4MB). 캡처 샤픈을 넣기 전에 잰 값이고, 기본 캡처 샤픈은 용량을 10%쯤 늘린다.

| 품질 | 깨끗한 사진 | 노이즈가 많은 사진 |
|---|---|---|
| 55 | 3.6MB | 7.1MB |
| 65 | 6.8MB | 11.1MB |
| 75 | 10.6MB | 15.1MB |
| 85 | 13.7MB | 16MB를 넘어 75로 낮춰짐 |
| 95~100 | 15.6MB | 70~75로 낮춰짐 |

- 영상 데이터가 16MB를 넘는 파일은 열지 못하는 뷰어(libde265 기반)가 있다. 그래서 넘으면 품질을 10씩 낮춰 다시 인코딩하고, 낮췄다는 것을 알린다. 낮출 때마다 인코딩을 한 번 더 하므로 그만큼 오래 걸린다.
- 95 이상은 결과가 같다.

## 결과 파일

- HEVC 4:2:0 10bit, sRGB. 확장자는 `.heic`.
- 촬영 정보(EXIF)를 그대로 옮기고, 세로로 찍은 사진은 바로 세워서 저장한다.

## 파일이 놓이는 곳

| 무엇 | 위치 |
|---|---|
| 프로젝트 | 직접 정한 곳의 `이름.amsil` 파일 하나 |
| 설정 (언어, 밝기 모드, 최근 프로젝트) | `~/.config/amsil/config.toml` |
| 직접 만든 프리셋 | `~/.config/amsil/presets/*.toml` |
| AI 모델 | `~/.local/share/amsil/models/` (`AMSIL_MODELS`로 바꿀 수 있다) |
| 로그 | `~/.local/state/amsil/log.txt` |

**로그.** 문제가 생겼을 때 원인을 볼 수 있도록, 일어난 일을 파일 하나에 남긴다. 창의 **[로그 열기]** 를 누르면 열린다. 명령행으로 쓸 때도 같은 파일에 남는다. 로그는 화면의 언어와 상관없이 영어로 쓴다 (다른 사람에게 보여 주거나 오류 문구로 검색하기 쉽게). 화면과 명령행의 안내는 그대로 고른 언어로 나온다.

```
2026-11-18 15:19:49 [info] Amsil 0.2.0 started: 사진폴더 출력폴더
2026-11-18 15:19:50 [info] Export started: 3 photos (3 at a time, quality 55)
2026-11-18 15:19:52 [error] Failed: 사진폴더/broken.ARW: Unsupported or damaged RAW file (…)
2026-11-18 15:19:58 [info] Export finished: done 2, skipped 0, failed 1 (8.1 s)
```

- 1MB를 넘으면 다음에 켤 때 `log.old.txt`로 옮기고 새로 시작한다.
- 사진 파일의 경로가 들어 있다. 다른 사람에게 보낼 때는 한번 훑어본다.

## 알아 둘 것

- Sony DSLR-A900의 ARW로만 확인했다. RAW 읽기는 rawler가 하므로 rawler가 지원하는 다른 Bayer 센서 카메라도 읽을 수 있지만 확인하지는 않았다. 색은 A900의 카메라 JPEG에 맞춰 두었다.
- Linux 전용이다.
- 화면의 언어를 고른 적이 없으면 시스템 언어를 따른다 (한국어 로캘이면 한국어, 그 밖에는 영어).
