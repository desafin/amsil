# 선예도 측정

캡처 샤픈의 조건(반복 횟수, 대비 문턱, 그 위에 더하는 창작 샤픈)마다 결과의 선예도를 카메라 JPEG와 견준다. 캡처 샤픈의 기본값과 프리셋의 샤픈을 정할 때 쓴다.

```
cargo test --release -- --ignored render_for_sharpness_measurement   # 몇 분 걸린다
python3 scripts/sharpness/measure.py                                  # numpy, Pillow 필요
```

샘플 사진(`DCIM/`)이 있어야 한다. 그림은 `/tmp/amsil-sharpness/`에 쓴다 (`AMSIL_SHARPNESS_DIR`로 바꿀 수 있다).

## 재는 것

사진마다 세부가 많은 2048×2048 영역을 256×256 구역으로 나누고, 캡처 샤픈을 끈 그림의 중간 대역 에너지로 "세부" 구역(위 15%)과 "평평한" 구역(아래 25%)을 고른다.

| 열 | 뜻 |
|---|---|
| 세부/카메라 | 세부 구역에서 0.15~0.35 cycles/pixel 대역의 진폭이 카메라 JPEG의 몇 배인가 (압축 전). 1이면 카메라와 같다 |
| 압축 후 | 같은 것을 품질 55로 압축했다 푼 그림에서 |
| 평평/끔 | 평평한 구역에서 0.25~0.45 대역의 진폭이 캡처 샤픈을 끈 그림의 몇 배인가 (노이즈가 얼마나 커졌나) |
| 넘침, 넘침% | 뚜렷한 경계 둘레에서 샤픈 전 5×5의 최댓값·최솟값을 넘은 정도 (평균 × 1000, 0.02 넘는 화소의 비율) |
| 용량 | 품질 55로 압축한 파일 크기, 캡처 샤픈을 끈 것에 대한 비율 |

진폭은 0.02~0.06 대역으로 맞춰서 비교하므로 밝기·대비의 차이는 빠진다. 고감도 사진은 카메라 JPEG가 노이즈를 강하게 지워서 "세부/카메라"가 선예도를 말해 주지 못한다.
